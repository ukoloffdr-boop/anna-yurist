Сколько лет можно взыскать долг (срок исковой давности)?

Общий срок исковой давности — три года. По обязательствам с определённым сроком исполнения он начинает течь по окончании этого срока. Для отдельных требований могут быть установлены специальные сроки.

Пошагово

  1. Определите дату, когда оплата должна была поступить.
  2. Отсчитайте три года с этой даты.
  3. Проверьте, нет ли специального срока для вашего вида требования.
  4. Не затягивайте: давность применяется судом по заявлению стороны спора.

Правовая основа

Когда нужен юрист

Если должник оспаривает долг, сумма значительна или договор составлен нечётко — юрист поможет выбрать порядок взыскания (претензия, исполнительная надпись, суд) и правильно рассчитать требования.
